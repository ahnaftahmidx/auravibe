# AURAVIBE — Where Every Beat Has a Feeling

AURAVIBE redesign package based on the previous Just Feel with Ahnaf website.

## Included
- Rebranded AURAVIBE identity and purple/electric-blue visual accents
- Cinematic intro on each page visit (5.2 seconds, with Skip)
- Name-only first entry; name is remembered in this browser using localStorage
- Returning visitor welcome experience; no email/password or Google login
- Existing music discovery, player, favorites, playlists, notes and settings retained

## Important limitations
- Name recognition is browser-local and is not identity verification. Clearing browser data or using another device requires entering the name again.
- The Audius online catalog and streams depend on third-party availability; not every track is guaranteed to play. Local audio files can be selected from the device.
- This is a static GitHub Pages site; no secure account system is included or needed for this name-only entry.

## Deploy
Extract the ZIP and upload all files to the root of your GitHub Pages repository, replacing files with matching names, then commit to the publishing branch. Test on the live site after GitHub Pages finishes deploying.
